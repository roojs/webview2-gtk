# Accessibility — Win32Atspi

Windows counterpart to Linux **atspi-2** / `Atspi.*`. Same shape of API (`init`, `get_desktop`, `Accessible`, actions, keyboard synth); backed by WebView2 UI Automation in the host.

```vala
Win32Atspi.init ();
var desktop = Win32Atspi.get_desktop (0);
var app = desktop.get_child_at_index (i);  // pid match
acc.get_role_name (); acc.get_child_at_index (j); acc.do_action (0);
acc.set_text_contents ("…");
Win32Atspi.generate_keyboard_event (...);
```

Prefix: **`Win32Atspi`** (C: `win32_atspi_`), parallel to **`WebView2Gtk`**.

`Win32Atspi.register_webview(web)` runs when the WebView attaches. UIA walk / invoke / set_value stay in the host backend — not methods on `WebView2Gtk.WebView`.

## Tree shape

```
Desktop
  Application (this pid)
    Frame  (action default.activate)
      Document ("document frame")  ← from UIA Document
        … page nodes (link, push button, combo box, …)
```

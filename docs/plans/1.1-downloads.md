**Split of responsibility (locked by Android 1.1 / 5.0.5):**

- **🔷** **This library** — WebKitGTK-shaped download *engine* API + actually transfer bytes to a destination the caller sets.
- **🔷** **OLLMchat** — permission UI (`ChatPermission`), activity events, `GLib.Notification`, in-flight dedupe, destination *policy* (which folder / filename).
- **🚫** No download-manager UI / history list in this library (**5.0.7** is OLLMchat).

---

## Purpose

- **🔷** Expose enough of WebKitGTK’s download surface that OLLMchat `Browser` can drop the Linux-only `#if` and run the same permission → place → progress → finish flow on Windows.
- **🔷** Use WebView2 `DownloadStarting` + cookie-aware WinHTTP under the hood — not a parallel Soup-only path that bypasses the WebView session.
- **🔷** Keep permission and banner UX out of this repo.

---

## Shipped API (this repo)

### `WebView2Gtk.WebView`

- **✔️** `Download download_uri (string uri)`
- **✔️** `get_network_session()` → cookies + **`download_started`**

### `WebView2Gtk.NetworkSession`

- **✔️** signal `download_started (Download download)`
- **✔️** `get_cookie_manager()`

### `WebView2Gtk.Download`

- **✔️** `get_request()` / `URIRequest.uri` / `get_uri()`
- **✔️** signal `bool decide_destination (string? suggested_filename)` (idle after started; return `true` to own destination)
- **✔️** `set_destination` / `set_allow_overwrite` / `cancel`
- **✔️** `get_received_data_length` + `received_data` / `finished` / `failed`
- **✔️** `get_mime_type` / `get_estimated_content_length` (from `DownloadStarting` when present)

### Host

- **✔️** `ICoreWebView2_4::DownloadStarting` → Vala `download_started` (default UI cancelled; we own transfer)
- **✔️** Suggested filename from `ResultFilePath` basename + URL basename
- **✔️** WinHTTP GET with WebView2 cookies + User-Agent; progress / finish / fail on GTK idle
- **✔️** `cancel` aborts in-flight transfer

### Destination

- **✔️** Caller passes a **filesystem path**; library writes there (mkdirs parent). Example uses `UserDirectory.DOWNLOAD` or tmp.

## LLM notes

- Mirror **5.0.5** call sites / Android **1.1** Vala shapes, not the entire WebKitGTK `Download` docs.
- Permission stays in OLLMchat — async gap between `decide_destination` and `set_destination` is supported.
- `download_started` lives on `NetworkSession` (with cookies).
- `download_uri` has no COM equivalent — same host transfer path as click downloads.

# 3.0 — Engine fill / click (CDP behind AT-SPI shapes)

**Status:** ⏳ proposed  

**Related:** [1.0-uia-accessibility.md](./1.0-uia-accessibility.md), [docs/a11y.md](../a11y.md)  
**Pattern reference:** `lib/host/win32-ui-webview2-capture.c` (`CallDevToolsProtocolMethod`)

ℹ️ Plan emoji: 🔷 user req, 💩 LLM suggestion, ⏳ backlog, 🚫 veto.

---

## Emulation rule (mandatory)

🔷 This library **only emulates existing WebKitGTK / AT-SPI APIs** so shared Vala (`#if WINDOWS` → `Win32Atspi` / `#else` → `Atspi`) can use the same shapes.

- 🔷 Copy **names, signatures, and semantics** from **atspi-2** (`Atspi.*`) / what Linux apps already call on WebKitGTK pages.
- 🔷 Approximate imperfect WebView2 / CDP behaviour **inside the host** so callers still see the AT-SPI contract.
- 🚫 Do **not** invent Windows-only public APIs (`input_click_sync`, `insert_text_sync`, `screen_to_viewport` on `WebView`, etc.).
- 🚫 Do **not** put consumer-app product names, plans, or workflows in this document.

---

## Purpose

- 🔷 Deliver **click + type** into the hosted page through **Chromium DevTools Protocol** (`Input.*`), not OS `SendInput`.
- 🔷 Public surface stays **`Win32Atspi`**, matching **`Atspi`** — same methods apps already use on Linux.
- ℹ️ UIA walk / invoke / ValuePattern remain available; this plan changes **how** keyboard / mouse synth and (optionally) set-text are delivered when the engine path is preferred.

---

## Why

- ℹ️ Host already uses DevTools for screenshots (`Page.captureScreenshot`).
- ℹ️ Today `generate_keyboard_event` → `vala_webview2_host_a11y_type_text` / `a11y_key_vk` use **SendInput**.
- 🔷 CDP `Input.dispatchMouseEvent` + `Input.insertText` / `Input.dispatchKeyEvent` inject into the page engine.

---

## Public API (exact Atspi shapes — no invention)

Canonical Linux (atspi-2). Implement / keep the **same** names under `Win32Atspi`:

```vala
namespace Win32Atspi {
	/* Already present — keep signatures; may change backend to CDP. */
	public void generate_keyboard_event (
		long keyval,
		string? keystring,
		KeySynthType synth
	);

	public bool Accessible.set_text_contents (string new_contents);
	public bool Accessible.do_action (int index);
	public bool Accessible.grab_focus ();

	/* Atspi has this; Win32Atspi does not yet — add with the same signature. */
	public bool generate_mouse_event (long x, long y, string name) throws Error;
}
```

| Atspi | Win32Atspi today | This plan |
|-------|------------------|-----------|
| `generate_keyboard_event` | ✅ SendInput | ⏳ CDP `Input.insertText` / `dispatchKeyEvent` for `STRING` / Enter |
| `generate_mouse_event (x, y, name)` | ❌ missing | ⏳ Add; CDP `Input.dispatchMouseEvent` for `b1c` (and press/release if needed) |
| `Accessible.set_text_contents` | ✅ UIA ValuePattern | ℹ️ Keep UIA default; 💩 optional CDP insert after focus — only if UIA fill fails in practice |
| `do_action` / `grab_focus` | ✅ UIA | 🚫 No API change |

### Coordinate space (`generate_mouse_event`)

- 🔷 Atspi: **screen** coordinates (`glong x, y`).
- 🔷 Host maps screen → WebView2 **CSS viewport** internally (HWND origin + DPI) before CDP. Mapping is **not** a public helper.

### Event `name` strings (Atspi)

Copy Atspi docs: e.g. `b1p`, `b1c`, `b1r`, `abs`, `rel`. Minimum for this plan: **`b1c`** (button-1 click).

## Host C (internal only — not public Vala)

Names may be private to the host `.c` file; Vala only sees Win32Atspi.

- 🔷 ⏳ Sync DevTools helper (same await pattern as capture).
- 🔷 ⏳ CDP: mouse press/release at viewport `(x, y)`.
- 🔷 ⏳ CDP: `Input.insertText` for UTF-8; `Input.dispatchKeyEvent` for Return/Enter.
- 🚫 Do not export `vala_webview2_host_input_*` as part of the WebKit-shaped public API.

Wire:

- `Win32Atspi.generate_mouse_event` → host CDP mouse  
- `Win32Atspi.generate_keyboard_event` (`STRING` / key) → host CDP text/key  
- Leave `a11y_type_text` / `a11y_key_vk` available as fallback or remove only in a follow-up

**Status:** ⏳

**Status:** ⏳

- 🔷 ⏳ Demo: focus field → `generate_keyboard_event (0, "hello", STRING)` → Enter.

**Smoke:** text appears; Enter fires as on Linux AT-SPI synth.

## LLM notes

- Public names must match **Atspi** / existing **Win32Atspi** — check valadoc / atspi-2 before adding anything.

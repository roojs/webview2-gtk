# 1.1 — Downloads (WebKitGTK-shaped, for OLLMchat 5.0.5 / 5.0.1)

**Status:** implemented

**Related:** sibling [webkitgtk-android `1.1-downloads.md`](file:///home/alan/git/webkitgtk-android/docs/plans/1.1-downloads.md); OLLMchat 5.0.5 / 5.0.1

---

## Split of responsibility

| Layer | Owns |
| ----- | ---- |
| **webview2-gtk** | `Download`, `download_uri`, `NetworkSession.download_started`, transfer to caller path |
| **OLLMchat** | Permission, Downloads folder, banner, notifications |

---

## API

```vala
public Download download_uri (string uri);
public signal void NetworkSession.download_started (Download download);

public class Download : Object {
	public URIRequest get_request ();
	public signal bool decide_destination (string? suggested_filename);
	public void set_destination (string path);
	public void set_allow_overwrite (bool allow);
	public void cancel ();
	public signal void received_data (uint64 data_length);
	public signal void finished ();
	public signal void failed (GLib.Error error);
}
```

---

## Host

- Click: `ICoreWebView2_4` `DownloadStarting` + deferral until `set_destination` → `ResultFilePath` + `DownloadOperation` progress/state
- Tool: `download_create` / WinHTTP GET with cookie jar from `get_cookies_sync`
- Files: `lib/host/win32-ui-webview2-downloads.c`, Vala under `lib/webview2gtk/`
